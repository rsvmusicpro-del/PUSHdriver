# Push 1 / Bitwig 64-color palette

PUSHdriver exposes exactly 64 color choices in the Color view. The menu slots remain 0–63; each slot selects one distinct RGB triplet from the existing Push 1 `DEFAULT_PALETTE` and registers the corresponding hardware LED index. Dark and weak entries have been replaced by vivid, saturated hardware colors. No pastel colors or synthetic RGB values are used, and no menu entries have been added.

This is a PUSHdriver palette derived from the Push 1 hardware palette, not a claim that Bitwig's built-in factory palette contains these exact 64 entries.

The 64 menu slots map to 64 distinct hardware palette indices and RGB values. The Color view continues to use all 64 pads on one page. The menu applies the selected RGB through the existing Bitwig track, clip and layer color APIs.
